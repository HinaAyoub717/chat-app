# Ripple: Real-Time Chat App (Frontend Only)

A chat interface built for my internship task. Messages appear instantly, replies are simulated automatically, and the whole conversation is saved in the browser.

Live demo: https://hinaayoub717.github.io/chat-app/

## Features
- Chat input and send button (Enter to send, Shift + Enter for a new line)
- Messages appear instantly in the chatbox
- Different styles for sent and received messages
- Simulated replies with a typing indicator
- Chat history saved in localStorage, so it stays after a page refresh
- Smooth scrolling and message animations
- Multiple conversations, search, and a "New chat" option
- Emoji picker and a "Clear chat" confirmation
- Responsive layout that works on phones and desktops

## Built with
HTML, CSS and JavaScript (no libraries)

## What I learned
- HTML structure for a messaging app
- CSS for a responsive chat UI
- JavaScript DOM manipulation (createElement, appendChild)
- Saving and loading chat history with localStorage

## How to run
Open `index.html` in your browser.
